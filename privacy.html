Privacy Policy — youtube-uploader

Effective date: October 10, 2026

What this application is

youtube-uploader is a private, single-user tool run by its owner on the owner's own computer. It uploads the owner's own video files to the owner's own YouTube channel using the YouTube Data API v3.

Data accessed

The application requests exactly one Google API scope: https://www.googleapis.com/auth/youtube.upload. It is used only to upload videos to the channel of the Google account that authorized the application. The application does not read, modify, or delete any other account data, and it does not access any other person's data.

Data stored

The OAuth credentials (including the refresh token) created by the owner's own authorization are stored only in a private, access-restricted directory on the owner's own machine. No data is transmitted to, stored on, or processed by any third-party server other than Google's own API endpoints, and no data is sold, shared, or used for advertising.

Revoking access

Access can be revoked at any time by the account owner at https://myaccount.google.com/permissions, which immediately invalidates the stored credentials.
